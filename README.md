
# Projetos JavaScript — Portfólio de Estudos

Repositório criado para reunir projetos práticos desenvolvidos durante meus estudos de HTML, CSS e JavaScript.

O objetivo é consolidar conhecimentos de desenvolvimento web, praticar lógica de programação e construir um portfólio com aplicações funcionais.

Os projetos estão organizados em pastas independentes, permitindo acompanhar minha evolução e os conceitos utilizados em cada aplicação.

## Projetos desenvolvidos

### 01 — Calculadora

Calculadora web com interface responsiva, desenvolvida utilizando HTML, CSS e JavaScript.

**Funcionalidades:**
- Operações matemáticas básicas.
- Interface moderna e responsiva.
- Suporte à utilização pelo teclado.

**Conceitos praticados:**
- Manipulação do DOM.
- Eventos de clique e teclado.
- Funções e operadores matemáticos.
- Estruturas condicionais.

**Acessar projeto:** [01 — Calculadora](./01%20-%20Calculadora/)

---

### 02 — To-Do List

Aplicação para gerenciamento de tarefas, com operações CRUD e armazenamento local.

**Funcionalidades:**
- Adicionar, editar e excluir tarefas.
- Marcar tarefas como concluídas ou pendentes.
- Filtrar tarefas por situação.
- Contador de tarefas pendentes.
- Persistência dos dados com localStorage.
- Edição diretamente na página.
- Interface responsiva e acessibilidade básica.
- Tratamento de erros de armazenamento.

**Conceitos praticados:**
- Manipulação do DOM.
- Eventos e funções JavaScript.
- Arrays e objetos.
- Métodos `forEach()`, `find()`, `filter()` e `reduce()`.
- `localStorage`, `JSON.stringify()` e `JSON.parse()`.
- Tratamento de erros com `try...catch`.

**Acessar projeto:** [02 — To-Do List](./02-todo-list/)

---

### 03 — Controle de Despesas Pessoais

Aplicação web para registrar e acompanhar receitas e despesas, visualizar o saldo total e filtrar transações.

**Funcionalidades:**
- Cadastro de receitas e despesas.
- Organização por categorias.
- Cálculo automático do saldo, das receitas e das despesas.
- Filtro de transações por tipo.
- Exclusão de transações.
- Armazenamento dos dados no navegador com `localStorage`.
- Interface responsiva.

**Tecnologias:** HTML, CSS e JavaScript.

**Acessar projeto:** [03 — Controle de Despesas](./03-controle-despesas/)

## Como executar os projetos

1. Clone ou faça o download deste repositório.
2. Abra a pasta do projeto desejado.
3. Execute o arquivo `index.html` em um navegador.

Também é possível utilizar a extensão Live Server no Visual Studio Code.

Os projetos utilizam HTML, CSS e JavaScript puro, sem necessidade de instalação de bibliotecas externas.
